## What is NexMind?

NexMind is a fully decentralized AI assistant built natively on the [Nesa Layer-1 blockchain](https://nesa.ai). Unlike traditional AI platforms that rely on centralized servers and opaque data pipelines, NexMind routes every inference request through Nesa's privacy-preserving network.

Your prompts. Your data. Your results. **Never exposed to any single party.**

---

## Why NexMind?

| Traditional AI | NexMind |
|---|---|
| Centralized servers | Distributed node network |
| Your data is harvested | End-to-end encrypted queries |
| Black box outputs | Cryptographic proof per response |
| Expensive GPU required | Runs on any hardware via Nesa |
| Closed model access | 120,000+ open models |

---

## Features

- **Private by default** — queries encrypted using Nesa's Equivariant Encryption (EE)
- **Verifiable outputs** — every response backed by a ZK proof on-chain
- **No GPU required** — powered by Nesa's global distributed node network
- **Open model access** — tap into 120,000+ AI models in Nesa's repository
- **Earn while you use** — NES token rewards for active participants
- **DAI native** — registered as a Decentralized AI Application on Nesa

---

## How It Works

```
User Query (encrypted)
       ↓
Nesa Layer-1 Blockchain
       ↓
Distributed Node Network (sharded inference)
       ↓
ZK Proof generated
       ↓
Verified result returned to user
```

No central server ever sees your full query or result.
