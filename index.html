// architecture

How it works.

Four steps. Zero trust required. Fully on-chain.

01

Submit encrypted query

Your prompt is encrypted before it leaves your device. The network never sees plaintext.

02

Model sharded across nodes

The AI model is split into pieces distributed across multiple nodes. No single node has the full picture.

03

Private inference executed

Nodes compute on encrypted data using Nesa's HSS-EE cryptography. Your data stays sealed.

04

Verified result returned

A ZK proof is generated, written on-chain, and the verified answer delivered to you.

user.query(encrypted) AES-256
nesa.routeToNodes() VRF
nodes.inferSharded() HSS-EE
chain.writeProof() ZK-SNARK
user.receive(verified) ✓ ON-CHAIN
